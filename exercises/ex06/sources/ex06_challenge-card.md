# Challenge Card

New requirement:

Critical Service Requests must automatically receive a due date no later than two working days after creation. A Critical request must not be resolved without an assignee. The behavior must remain visible through the existing OData V4 UI service.

Rules:
- Do not tell the agent team how to implement the requirement.
- Architect first.
- Human approval before code.
- Developer implements and tests.
- Reviewer independently reviews.
- Use released APIs only for SAP standard dependencies.
- Stay inside the participant package.
