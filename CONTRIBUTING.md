# Contributing

## Engaging in this project

Use GitHub issues to report workshop problems, confusing steps, outdated screenshots, or agent/tool behavior that no longer matches the instructions. When possible, include the exercise number, the prompt used, the ADT for VS Code version, and the observed result.

## Pull requests

Pull requests are welcome for corrections and workshop improvements. Keep participant-facing instructions concise, reproducible, and compatible with the SAP S/4HANA workshop target.

This repository intentionally does not bundle agents, skills, or MCP servers. Contributions should preserve that boundary and treat those components as external prerequisites.
